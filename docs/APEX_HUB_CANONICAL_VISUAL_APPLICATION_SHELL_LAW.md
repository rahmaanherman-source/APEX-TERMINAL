# APEX HUB — CANONICAL VISUAL APPLICATION SHELL LAW

**Status:** CANONICAL / NON-NEGOTIABLE
**Scope:** APEX Hub application shell, landing/entry experience, visual references, navigation, modules, views, panels, tabs, and application boundaries

## 1. Canonical Rule

The provided APEX Hub reference images represent **ONE APEX HUB APPLICATION SHELL / CANONICAL LANDING-ENTRY EXPERIENCE**.

They are **not separate landing pages**.

The images show different functional views, modules, panels, tabs, workspaces, and application states within the same APEX Hub experience.

They establish the intended visual architecture, information hierarchy, navigation model, modular organization, and functional character of APEX Hub.

## 2. APEX Hub Landing Experience

When the authorized Developer / Owner enters APEX Hub, the user enters the canonical APEX Hub command-center experience.

The landing/overview experience is a functional application environment, not merely a marketing page or decorative hero.

It establishes the APEX Hub identity and provides access to system intelligence, projects, applications, assets, operational information, navigation, and governed actions.

## 3. Terminology — Canonical Definitions

- **Page:** An actual application destination or route.
- **Landing / Entry Experience:** The initial destination and front-door experience through which the user enters an application.
- **View:** A particular presentation or state of the current application workspace.
- **Module:** A functional subsystem within the application.
- **Panel:** A contained interface area for related information or controls.
- **Tab:** A navigation control that switches between related views.
- **Workspace:** The functional environment in which the user performs work.
- **Application:** A complete APEX product or environment with its own functional boundary.
- **Hero:** The primary visual/experience area used to establish the identity and purpose of a page or application entry experience. A hero is not synonymous with the entire application and is not necessarily only an image.
- **Hero Image:** A prominent image used within a hero area.
- **Theme:** The overall visual identity and styling system.
- **UI:** The interface elements through which the user interacts with the system.
- **UX:** The organization and behavior of the user's overall experience.
- **CSS:** Code controlling presentation/styling in a web application.
- **Component:** A reusable interface element.

APEX Hub is the command and navigation environment. Separate APEX applications remain separate applications.

Examples:

```text
APEX HUB → TERMINAL → APEX TERMINAL WORKSPACE
APEX HUB → HERITAGE → APEX HERITAGE WORKSPACE
APEX HUB → 360 → APEX 360 WORKSPACE
APEX HUB → STUDIO → APEX STUDIO WORKSPACE
```

Each separate application retains its own identity, navigation, functionality, data, workspace, controls, modules, and visual language.

Shared infrastructure is permitted.

Feature bleed and visual bleed are not permitted unless explicitly authorized.

## 7. Functional Requirement

Every visible navigation item, tab, button, module, panel, and action must either:

1. perform its intended function;
2. navigate to its intended destination;
3. open its intended functional module; or
4. clearly report that the capability is unavailable, unconfigured, blocked, failed, or otherwise not ready.

Decorative controls must not masquerade as functional controls.

## 8. Truth Requirement

APEX Hub must obey the APEX evidence standard.

The UI must never convert appearance into truth.

Examples:

- `VERIFIED` requires actual supporting evidence.
- `CONNECTED` requires actual connection evidence.
- `DEPLOYED` requires evidence that deployment occurred.
- `DEPLOYMENT_VERIFIED` requires verification of the deployed system.
- `READY` requires the applicable readiness conditions to be satisfied.
- `UNVERIFIED` means sufficient evidence does not exist.
- `UNKNOWN` means the current state cannot be established.
- `BLOCKED` means execution is prevented by an identified condition.
- `FAILED` means an actual failure has been observed.

No fake green.
